# Lijnbaansgracht 204-1 Guest Portal

Premium guest portal for Lijnbaansgracht 204-1, a historic Amsterdam canal apartment.

## Features

- **Hero Section** - Welcome with building illustration
- **Check-in Guide** - Entry code (2610) with step-by-step instructions
- **Apartment Tour** - Interactive carousel and clickable floorplan
- **House Rules** - Clear guidelines for guests
- **House Guide** - Comprehensive accordion with all information
- **WiFi Details** - Network and password with copy-to-clipboard
- **Check-out Checklist** - Interactive cleaning checklist
- **Neighborhood** - Local recommendations
- **Footer** - Personal welcome from Jimmy

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Building for Production

```bash
npm run build
npm start
```

## Deployment

Deployed on Vercel. Push to main branch to auto-deploy.
